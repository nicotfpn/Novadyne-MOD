# Valves · tiers e chance de sucesso

Coloque uma valve no slot dedicado da Lithography. Ela permanece no slot após o processo. As porcentagens abaixo são do **engraving**; a limpeza com água não usa RNG.

| Valve | Sucesso | Falha |
| --- | ---: | ---: |
| Sem valve | 70% | 30% |
| [Valve (Tier 1)](itens/valve_tier_1.md) | 70.00% | 30.00% |
| [Valve (Tier 2)](itens/valve_tier_2.md) | 74.17% | 25.83% |
| [Valve (Tier 3)](itens/valve_tier_3.md) | 78.33% | 21.67% |
| [Valve (Tier 4)](itens/valve_tier_4.md) | 82.50% | 17.50% |
| [Valve (Tier 5)](itens/valve_tier_5.md) | 86.67% | 13.33% |
| [Valve (Tier 6)](itens/valve_tier_6.md) | 90.83% | 9.17% |
| [Valve (Tier 7)](itens/valve_tier_7.md) | 95.00% | 5.00% |

Chance por tentativa, não uma garantia em lotes pequenos. Os sete crafts são sem posição fixa.
